# Ubisafe

GPS Platform for Fleet Management & Anti-Theft

## Stack

- **Backend:** Node.js + Express + PostgreSQL/TimescaleDB
- **Frontend:** React + Vite + Google Maps API
- **Deployment:** Railway + Cloudflare

## Features

- Real-time vehicle tracking
- Fleet management
- Anti-theft alerts
- Multi-tenant support
